# Getting started with Chat TPG

Chat TPG is a knowledge-based chat client. You can ask questions and the assistant will use the files in this `knowledge/` folder to answer.

## Example questions

- "What is in the knowledge base?"
- "Summarize the README in the knowledge folder."
- "List the files you can read."

Add more `.md` or `.txt` files to this folder to expand what the assistant can use.
